What to look for

Seahorse vs Elephant vs Triple Spiral. Same rule, same iteration, wildly different local decoration. If the set were self-similar these would converge to one picture. They don't — the local structure encodes your address.

Misiurewicz c = i. Compare the main view to the Julia inset as you dive. They converge on each other. That's Tan Lei's 1990 theorem: at Misiurewicz points the Mandelbrot set is asymptotically similar to the corresponding Julia set — not to itself.

Feigenbaum point. The one landmark that is asymptotically self-similar, repeating at ratio δ = 4.669…, the same constant that governs period-doubling in dripping taps and heart arrhythmias.

Speckle. Near a chaotic boundary a pixel can sit on a knife edge where a one-bit difference flips its escape count by hundreds. WebGL has no doubles, and measured against exact ground truth, emulating them costs about 6× the shader time to remove only a third of the visible speckle — a bad trade. 4x samples is the better one: it doesn't correct a bad sample, it dilutes it to quarter weight. Turn it off to see the difference. The real cure is per-pixel glitch detection against multiple reference orbits, which is what dedicated software does.

On "infinite". There's no hard wall now — precision grows with depth automatically. But each decade down needs more iterations and more bits, so the cost climbs without bound. You can always go one more level. You can never go all the way. Raise Iteration budget when detail turns to mush; that's the signal you've outrun it.
